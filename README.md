# 🌐 HTML & CSS Basics

Welcome to my **HTML & CSS Basics** repository!  
This repo is a part of my web development journey, where I'm learning and practicing the core building blocks of the web — HTML (HyperText Markup Language) and CSS (Cascading Style Sheets).

---

## 📁 What’s Inside?

- **HTML Practice:**  
  Simple webpages built using HTML5 structure and tags like headings, paragraphs, images, links, lists, and tables.

- **CSS Styling:**  
  Basic styling using inline, internal, and external CSS. Includes work with colors, fonts, margins, paddings, borders, and layout models.

- **Mini Projects:**  
  Small webpage examples like a personal bio page, simple landing pages, etc., to implement and reinforce learning.
